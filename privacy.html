A112 Rclone Bridge

Privacy Policy

Effective date: November 16, 2026

Purpose and scope

A112 Rclone Bridge is a non-commercial personal configuration of Rclone used by its owner to synchronize selected files between an Ubuntu server and a Google Drive account. This policy describes that configuration and its public informational website.

Google user data accessed

With the account owner's authorization, Rclone accesses Drive files and associated metadata necessary to list, read, create and update files according to the configured synchronization commands. The selected OAuth scope may technically authorize broader Drive access than the specific folders used by those commands.

Use and storage

Drive data is used solely for file transfer and synchronization initiated by the account owner. Files are stored in the owner's Google Drive and/or the owner's Ubuntu server. Rclone stores OAuth credentials on the owner's server in its configuration file, which should be protected with appropriate file permissions.

Data disclosure

The owner does not sell Google user data or use it for advertising. The synchronization setup does not operate a third-party data-sharing service. Google Drive provides cloud storage; this public informational website does not receive Google Drive contents or OAuth credentials.

Website hosting

This informational website does not use custom analytics, advertising trackers, sign-in forms or cookies of its own. It is hosted by GitHub Pages, and GitHub may process normal web-request information under its Privacy Statement.

Retention and deletion

Files are retained until the owner deletes them from Google Drive and/or the Ubuntu server. Revoking access does not automatically remove previously synchronized copies. The owner can delete those copies manually.

Revoking access

The owner can revoke the application's Google account access through Google Account connections and delete the local Rclone configuration or authorization tokens.
