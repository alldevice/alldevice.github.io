A112 Rclone Bridge

A112 Rclone Bridge is a personal, non-commercial setup using Rclone and the Google Drive API to exchange selected project files between an Ubuntu server controlled by the account owner and the owner's Google Drive.

How it works

Rclone transfers files within the user's configured folders. The synchronization is run by the account owner; this website is informational and does not perform synchronization.

Google Drive permissions

Rclone may request permission to access and manage Google Drive files. Although the synchronization commands target selected folders, the Google authorization may grant access to a larger part of the owner's Drive.

There is no public user registration or hosted service. This site does not collect Google login details, Google Drive files or OAuth tokens.

Read the Privacy Policy for details about processing, storage and revocation of access.
